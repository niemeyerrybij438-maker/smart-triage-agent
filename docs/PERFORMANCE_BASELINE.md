# 智医导诊平台性能基线

## 1. 测试说明

- 测试日期：2026-07-15
- 测试环境：Windows 本地开发环境、Go go1.25.1 windows/amd64、本地 MySQL
- 请求规模：每个接口 50 次请求
- 并发数：10
- 测试范围：患者端、医生端和管理端只读 HTTP 接口
- 排除范围：/api/chat、模型调用、向量生成和百度地图等计费或外部网络接口
- 通过标准：错误率为 0，P95 不超过 4000 ms

该基线用于衡量本地 API 和数据库访问性能，不代表公网部署、真实医院网络或大模型响应性能。

## 4. 本轮优化

1. 为 GORM 底层 database/sql 配置最大连接数、空闲连接数、连接生命周期和空闲回收时间。
2. 消除分诊记录列表中的重复患者档案查询，同一手机号只读取一次当前档案。
3. 对随访状态与通知生成增加并发保护和短时刷新节流，避免只读请求反复执行通知写入。
4. 将管理端仪表盘的多次逐项统计改为条件聚合查询，并将七日趋势改为一次分组查询。
5. 管理端分诊分析仅查询列表实际需要的字段，减少无用长文本传输。
6. Agent 轨迹改为轻量列表和详情按需加载，避免首页一次传输大量 Agent 输出内容。
